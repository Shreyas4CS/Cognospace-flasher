The shelf, by class

Each activity carries a code students can read out loud, so a teacher can say “flash CS-G07-A05” and every Coggy in the room ends up running the same firmware.

How upload the code into the coggy

Three moves, the same every time, on any machine in the lab.

Plug in the Coggy

Connect over USB and press Connect. Pick the board from the short list the browser shows — a fresh Coggy means a fresh pick every time — and the flasher reads the chip, the adapter and the MAC address back to you.

Pick the activity code

Filter by grade or search the code. The card shows the board it targets, the version and the components the activity needs.

Write and watch

Press Flash. The console prints every step, and the serial output appears as soon as the board restarts — useful evidence for a lab record.
