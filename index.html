How to flash a Coggy

Three moves, the same every time, on any machine in the lab.

Plug in the Coggy

Connect over USB and press Connect. Pick the board from the short list the browser shows — a fresh Coggy means a fresh pick every time — and the flasher reads the chip, the adapter and the MAC address back to you.

Pick the activity code

Filter by grade or search the code. The card shows the board it targets, the version and the components the activity needs.

Write and watch

Press Flash. The console prints every step, and the serial output appears as soon as the board restarts — useful evidence for a lab record.

For educators

A wiring sheet on every card

Tap Wiring on any activity to show the class which part goes on which Coggy pin. Each wire is colour-coded by type, the dots run the way the signal flows, and the sheet prints cleanly for the bench.

Adding your own activity

Export the compiled binary from the Arduino IDE, drop it into the class folder, add one entry to the catalogue block in this file, and push. Include CoggyWiring.h in the sketch and its wiring sheet builds itself. Vercel rebuilds in seconds.
